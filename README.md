# Проект «Полезный педагог» (Useful Pedagogue)

Экосистема для детского центра: PWA-приложение для родителей, педагогов и администрации.

## Статус проекта
**Текущий этап:** Создание инфраструктуры (Диалог №1).  
Все последующие этапы распределены по диалогам №2–№5.

## Как запустить инфраструктуру
1. Установите Docker и Docker Compose.
2. Скопируйте `.env.example` в `.env` и заполните своими данными (или оставьте как есть для теста).
3. Выполните в терминале из корня проекта:
   ```bash
   docker-compose up -d
